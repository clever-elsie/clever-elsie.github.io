work

競技プログラミング（AtCoder等）をC++で行う際の操作を徹底的に簡略化するための競プロ専用環境です。
WSL2 Ubuntu上で動作し、テンプレート展開・自動コンパイル・テスト・入力生成・ライブラリ管理など、競プロに必要な一連の作業をコマンド一発で効率化できます。

  • 主な内容: C++競プロ用テンプレート、Makefile、テスト自動化、ライブラリ自動展開、入力生成スクリプトなど
  • GitHub: work

特徴

  • テンプレート初期化・展開、コンパイル、テスト、入力生成、実行、時間計測などをコマンド一発で実行
  • 自作ライブラリやACLの自動展開・管理
  • Makefileやスクリプトによる柔軟なビルド・テストフロー
  • オンラインジャッジツール（ojt）連携
  • WSL2 Ubuntu 22.04以降に対応

使い方例

n   : テンプレ初期化
e   : 編集開始
c   : コード展開＆クリップボードコピー
t   : テスト自動実行
m   : 実行（必要なら自動コンパイル）
g   : デバッグ実行
z   : 手動コンパイル
r   : テスト入力編集
gen : 入力生成
T   : 実行時間計測
acl : ACL展開
lib : ライブラリプリコンパイル
ojt : online-judge-tools連携

備考

  • 一般的な作業用リポジトリではなく、競技プログラミング専用の効率化環境です。
