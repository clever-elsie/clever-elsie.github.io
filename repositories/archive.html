archive

home-server system。C++23 と CrowCpp/nginx を用いたミニマルな自宅サーバー用アーカイブ＆ビューア/メモシステム。JWT 認証と JSON ストレージ、OpenSSL によるハッシュ化などを採用しています。

  • 主な機能: 画像/動画/音声/テキストの閲覧、タグ付け、検索、メモ管理、ユーザー管理
  • 技術: C++23、CrowCpp、nginx、OpenSSL、フロントは HTML/CSS/JS
  • ライセンス: MIT
  • GitHub: clever-elsie/archive

注意事項

  • 初回ユーザー作成は誰でも可、初回は自動で管理者権限
  • データは users.json に保存、パスワードはソルト付ハッシュ
  • nginx 設定で公開パス制御（web/ と src/frontend/ のみ）

構成

archive/
├── includes/ ... マネージャやアプリのヘッダ
├── src/frontend/ ... Viewer/Memo のフロント
├── src/server/ ... Crow ベースのサーバ
├── web/ ... 画面 (index, viewer, memo, user_register)
└── config/ ... systemd, nginx, param.json など
