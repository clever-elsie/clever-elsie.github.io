jpp

jppは自作JSONライブラリです． cptを書いてるときに構造化文書のパーサも書いてみたいと思ったので書いただけで，普通にnlohmann/jsonなんかを使った方がいいと思います．

主な特徴

  • json::value クラスを使用した直感的なJSON値の表現（Null、Boolean、Number、String、Array、Object に対応）
  • 文字列化およびパース機能（\uXXXX サロゲートペアから UTF-8 への変換を含む）
  • 各種コンテナや文字列型からの容易な構築（u8 系も含む）
  • テストランナーによる入出力の自動検証

ドキュメント

  • API の詳細は docs/include.md に記載されています
  • ツールの概要は docs/src.md を参照してください

テストの実行方法

  1. テストケースを test/cases/*.json に配置します
  2. 以下のコマンドでビルドおよび実行します： 
    g++ -std=c++20 -O2 -Iinclude src/test_runner.cpp -o test_runner
./test_runner           # 比較
./test_runner --update  # 期待値更新
